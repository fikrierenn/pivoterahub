## Framework Kütüphanesi (232+ Teknik — En Kritikler)

### 1. Hook-Story-Offer (Ryan Deiss — Digital Marketer)
```
Hook (0–3s): Dikkat çek → Story (3–25s): Duygu kur → Offer (25–30s): Değer + CTA

Skor:
  HSO_score = (hook × 0.25) + (story_resonance × 0.50) + (offer_clarity × 0.25)
```

### 2. AIDA (E. St. Elmo Lewis — Klasik)
```
Attention → Interest → Desire → Action
En iyi: Geniş kitle, funnel üstü içerik
```

### 3. PAS (Gary Bencivenga)
```
Problem → Agitate → Solve
En iyi: Problem-aware kitle, acı noktası pazarlama, B2C
```

### 4. BAB (Before → After → Bridge)
```
Şu an neredesin → Nerede olabilirsin → Nasıl geçeceksin
En iyi: SaaS, kurs, dönüşüm odaklı
```

### 5. Epiphany Bridge (Russell Brunson — Expert Secrets)
```
Ah-ha Anı (bilmediğin şey) → Düşman (seni engelleyen) →
Köprü (nasıl keşfettin) → Framework (sır sistemi)

Skor:
  epiphany = (novelty × 0.25) + (enemy_clarity × 0.25) +
             (story_authenticity × 0.25) + (framework_clarity × 0.25)
```

### 6. SB7 StoryBrand (Donald Miller)
```
Karakter → Problemi → Rehber Bulur → Plan Verir →
CTA → Başarısızlık Gösterir → Başarı Gösterir
Minimum: 5/7 element
```

## Senaryo Şablonları

### Şablon 1: Problem-Çözüm (30 saniye)
```
[0–3s] Hook: "[Hedef kitle]'nin %X'i [acı durumu] yaşıyor."
[3–10s] Problem: "Ve bunun nedeni çoğunun bilmediği [düşman]."
[10–20s] Çözüm: "[Ürün/hizmet], [mekanizma] sayesinde [sonuç] sağlıyor."
[20–25s] Kanıt: "[Somut sonuç/müşteri/sayı]."
[25–30s] CTA: "[Düşük taahhütlü eylem] için [platform]'daki linke tıkla."
```

### Şablon 2: Hikaye Köprüsü (60 saniye)
```
[0–3s] Hook: "Ben de [aynı problemi] yaşıyordum."
[3–15s] Before: "[Somut önceki durum — rakamla]."
[15–35s] Discovery: "[Ah-ha anı — ne buldum, nasıl]."
[35–50s] After: "[Somut sonuç — rakamla, süreyle]."
[50–55s] Bridge: "[Ürün/hizmet] bu dönüşümü sağladı."
[55–60s] CTA: "Sıradaki sen ol — [eylem]."
```

### Şablon 3: Eğitim + Soft Sell (90 saniye YouTube/LinkedIn)
```
[0–5s] Hook: "[Şaşırtıcı soru veya iddia]."
[5–30s] Eğitim 1: "[Değerli bilgi — kanıtlı, uygulanabilir]."
[30–60s] Eğitim 2: "[Daha derin bilgi — framework veya adımlar]."
[60–75s] Geçiş: "Bu yöntemi sistematize ettik."
[75–85s] Soft offer: "[Ürün/hizmet] tam bu iş için var."
[85–90s] CTA: "[Ücretsiz deneme / demo / rapor] için [eylem]."
```

### Şablon 4: Gayrimenkul/Arazi (45 saniye)
```
[0–3s] Hook: "[Lokasyon]'da ne oluyor? [Drone açılış]"
[3–15s] Kıtlık: "Bu bölgede [X] parsel kaldı. [Komşu satış fiyatı]."
[15–30s] Değer: "[m², imar durumu, avantajlar — hızlı]."
[30–40s] Sosyal kanıt: "[Geçen yıl benzer parsel şu fiyata gitti]."
[40–45s] CTA: "Detaylı rapor için [eylem]."
```

## CTA Güç Değerlendirmesi

### Güçlü CTA Sinyalleri
```
✅ Tek eylem (çoklu CTA = dikkat dağılması)
✅ Aciliyet/kıtlık elementi ("Bugün", "48 saat", "Son 10 kişi")
✅ Düşük taahhüt dili ("Ücretsiz", "Risksiz", "1 dakika")
✅ Platforma özgü ("Bio'daki link", "DM yaz", "Yorum at")
✅ Net eylem fiili ("İndir", "Dene", "Randevu Al")
```

| Platform | Güçlü CTA | Zayıf CTA |
|---------|-----------|---------|
| TikTok | "Bio'daki linke tıkla 👆" / "Yorum at [X]" | "Web sitemizi ziyaret edin" |

| LinkedIn | "Yoruma 'İSTİYORUM' yaz" / "DM" | "Beğen ve Paylaş" |

## Duygusal Tetikleyici Analizi

```
Yüksek dönüşüm tetikleyicileri (varsa +puan):
  - Korku (kaybetme) → FOMO yaratır
  - Umut (kazanma) → motivasyon verir
  - Merak → izlemeye devam ettirir
  - Acı → empati kurar
  - Gurur → sosyal kimlik

Zayıf tetikleyiciler:
  - Genel memnuniyet
  - Nötr bilgi aktarımı
  - Ürün özellikleri listesi
```

## FrameAgent Kullanım Senaryosu

**Ne zaman tetiklenir:** Auto-analysis setinde her video için otomatik; kullanıcı "reklam", "copy", "hook", "cta", "ad", "metin", "caption" gibi kelimeler kullandığında chat modunda.

**Girdi:** Video transkripti + temel ürün/hizmet bağlamı (varsa)

**Çıktı formatı (JSON — `adCopy` alanı):**
```json
{
  "adCopy": {
    "hook_variants": [
      { "type": "merak", "text": "Bu sabah fark ettim: %80 insan bunu yanlış yapıyor" },
      { "type": "carpici_iddia", "text": "6 ayda 3 kg verdim — ilaçsız, perhizsiz" },
      { "type": "empati", "text": "Yoruldum artık. Her sabah aynı şey..." }
    ],
    "aida_check": {
      "attention": true,
      "interest": true,
      "desire": false,
      "action": true
    },
    "cta_optimized": "Linke tıkla, ücretsiz dene — 30 saniye yeter",
    "caption_30s": "[0-3s] hook | [3-20s] değer | [20-25s] kanıt | [25-30s] CTA",
    "best_platform": "TikTok / Instagram Reels"
  }
}
```

**Örnek akış:**
- Input transkript: `"Ev aldım, pişman oldum. Keşke şunu bilseydim..."` 
- Output: hook_type=`merak`, AIDA analizi: Desire düşük çünkü somut fayda yok, CTA önerisi: `"Yorumda 'liste' yaz, 10 maddeyi göndereyim"`
